منصة تعليمية متكاملة لمدارس حديد عز الرقمية — تعمل أوفلاين 100% وتدعم عرض ملفات PDF بشكلها الأصلي.

## 🎯 المميزات

- 📚 **منهج متكامل**: مقسم حسب المواد الدراسية
- 📖 **عارض PDF أصلي**: عرض الملفات كما هي مع تقليب الصفحات ورقة ورقة
- 🔍 **بحث فوري**: في القاموس والدروس والتعريفات والأسئلة
- 🃏 **بطاقات تفاعلية**: للتعريفات
- 📝 **بنك أسئلة**: مع تصحيح تلقائي
- 🎯 **اختبار سريع**: مع حفظ أفضل نتيجة
- 🌙 **وضع ليلي / نهاري**
- 💾 **حفظ التقدم**: يُحفظ محلياً في المتصفح

## 🚀 طريقة الاستخدام

1. افتح المنصة من الرابط
2. اختر المادة من القائمة الجانبية
3. اضغط على أي درس للاطلاع عليه
4. لعرض ملف PDF كامل: الصق رابط الملف ثم اضغط 👁️ عرض

## 📁 إضافة ملفات PDF

1. ارفع ملف PDF على GitHub في مجلد المادة المناسب
2. افتح الملف → اضغط زر **Raw** → انسخ الرابط
3. في المنصة: الصق الرابط مع اختيار المادة والنوع
